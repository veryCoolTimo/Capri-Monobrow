волосами), а не Capri из сериала. Разобраны четыре репозитория из `docs/MVP_SPEC.md` §13 (клоны — в

## Как выглядит Capri (из CHARACTER_DOSSIER capri-companion и рефов Тимофея)

- Плоская графика из острых осколков, без градиентов; единственная текстура — белые блёстки на гриве.
- Огромная малиновая грива (#F2154C), втрое шире плеч, выше головы; длинные пряди-молнии вниз.
- Под каждой формой — фиолетовая сдвинутая копия (#8A3DFF), как сбитая печать: это её «освещение».
- Крошечная чёрная угловатая голова с острым подбородком и шипами-короной; чёрная чёлка.
- Неоново-зелёная маска (#22F27A) из двух половинок с вырезом между глазами.
- Глаза — острые чёрные миндалины с шипами, зелёное кольцо, синяя радужка (#1D6CFF), белый зрачок; глаза
  разные по размеру и наклону.
- Рот — тонкий белый зигзаг; открытый — сплошной белый «клык»; маньячная ухмылка — щель с зубами.
- Тело чёрное, асимметрично: зелёная панель с одной стороны, малиновая «молния» с другой.

Почему не вышло у Codex: генерация по рефам каждый раз «очеловечивала» её (обычное лицо, волосы), а правки кадров
не дают точных поз. Оба чужих проекта пришли к тому же: лицо рисуется кодом.

## Приёмы анимации (capri-desktop, только как образец)

- Рисунки «на двойках» — 12 в секунду, как в аниме; без твинов: позы держатся, между ними — ключевые рисунки.
- «Кипение» линии: каждый рисунок чуть иначе (три фазы по кругу), лицо жёсткое, грива живёт вокруг.
- Плавание — четыре рисунка по 6 кадров, не синусоида.
- Глитч «relic»: сдвинутые горизонтальные полосы и RGB-разнос; зелёная и красная копии — «другие разумы».
- Когда Claude ждёт тебя — «все её глаза»; во сне от неё остаётся только маска (её «чип») с закрытыми глазами,
  открываются, когда ждут ответа.
- «Уменьшить движение» — только смена рисунков без движения.

## coucou — notch (механика, MIT)

- Ширина выреза = ширина экрана − `auxiliaryTopLeftArea` − `auxiliaryTopRightArea`; высота — `safeAreaInsets.top`.
- Открытие `.spring(response: 0.5, dampingFraction: 0.72)`, закрытие `timingCurve(0.45, 0, 0.2, 1, 0.34)`.
- Персонаж в notch — `Canvas` + `TimelineView(paused:)`, ~20 pt в компактном виде; кадровый интервал `0.9/fps`.
- Компактный вид: сетка мини-ботов по ждущим сессиям, «+N» при переполнении; узкая полоска-таймер снизу.
- Клики сквозь панель: `ignoresMouseEvents` переключается опросом позиции курсора (60 Гц рядом, 8 Гц далеко).

## Codeman — удалённые сессии (MIT)

- Ввод в tmux: текст одним bracketed paste (`set-buffer` + `paste-buffer -p -d`), Enter отдельно; одиночный
  символ для меню — `send-keys -l`. Проверка отправки: перечитывать панель, пока строка ввода ещё содержит
  отправленное — повторить Enter (Claude Code иногда игнорирует Enter сразу после появления поля).
- Codex без хуков: диалоги распознаются по экрану регулярками, только как сигнал, без нажатий.
- «Входящие одобрения»: одна очередь, не больше одного пункта на сессию, защита от двойного ответа.

## Что сделано в Capri

Два векторных варианта (маска из двух плашек по `face.ts`; свой крупный план по рефам) Тимофей отклонил —
не похоже. Итог: локальный Codex получил только рефы и короткую задачу и сам сгенерировал кадры состояний и
мини-маски (`work/art/v3/`); у нас — только склейка лица поверх общего кадра, чтобы грива не дрожала, и
показ кадров (`CapriSprite`, `CapriMaskSprite`). Приёмы capri-desktop из списка выше пока не перенесены.

## Рефы v4 — разбор (после «лучше, но не то»)

Набор: 8 рефов Тимофея + кадры из capri-desktop (`assets/capri`: лица, cut-in, интро) + `reference/cutouts`
capri-companion. Всё только как рефы для генерации, в репозиторий не попадает (`work/art/v4/refs`).
Чего не хватало v3 (там лицо чёрное с зелёными пятнами, грива закрывает лицо, без блёсток):

- лицо — почти целиком плоская неоново-зелёная маска, две половины, чёрный V-вырез со лба;
- глаза огромные: чёрная миндалина, тонкое зелёное кольцо, крупная синяя радужка, белый овальный блик;
- под маской — чёрная челюсть, рот — тонкая белая молния-зигзаг; открытый — большой белый рваный клык;
- маленькая чёрная угловатая голова с шипами-короной; грива — огромное малиновое облако с плотными белыми
  блёстками и фиолетовым сдвигом;
- лучшая основа «голова и плечи» — интро capri-desktop (зелёная маска, клык, корона, малиновое тело с глифом).

Инструмент генерации Codex берёт не больше 5 картинок, поэтому рефы склеены в две доски (крупные планы лица;
силуэт и грива) + 3 отдельных кадра.

## v5 — только глаза (после «лучше, но не идеально»)

Тимофей: моноброви не нужен целый персонаж — хватит её глаз крупным планом, как в сериале. В эпизодах с Capri
(YouTube, кадры отобраны по доле зелёного и синего) есть канонический ход: глаза в упор рассматривают →
закрываются → по маске открывается много глаз. Это и стало набором кадров: open, blink, squint, look-left,
look-right, slits, many, speakA, speakB — одна полоса маски 2:1, idle «рассматривает», alert — «много глаз».
Кадры сериала — только рефы (`work/`), в репозиторий не попадают.
