# Capri — компактный notch, помощник и персонаж (план по фидбеку 2026-10-30)

Исходник: `work/feedback-2026-10-30.md`. Решения приняты здесь, Тимофей смотрит результат.

## 0. Сначала баги

1. **Окно само вылезает поверх полноэкранных приложений (высокий приоритет).** Окно показывается только
   по явному действию: «подробнее» в notch, клик по уведомлению, Dock/Launchpad/Spotlight, пункт меню.
   Скрипты установки и перезапуск из настроек запускают Capri с `--background`; второй экземпляр с
   `--background` не просит первый показать окно. Окно — обычное (`.normal`, `.managed`, без
   `canJoinAllSpaces`/`fullScreenAuxiliary`). Старый бродящий персонаж прототипа (панель на всех Spaces)
   удаляется целиком.
2. **Имена сессий.** Заголовок — имя tmux-сессии целиком (`votek2`), рядом проект по папке, если он
   другой. Несколько сессий в одной tmux-сессии различаются окном/панелью (`votek · 1.2`). Логика имён —
   в CapriKit (`SessionNames`) с тестами.
3. **Список не прыгает.** Группы: ждут меня → работают → остальные. Внутри «ждут меня» — по времени
   начала ожидания (оно не меняется, пока сессия ждёт); в остальных — по стабильному ключу
   (хост в порядке настроек, имя tmux-сессии, окно.панель). Свежесть событий на порядок не влияет.
   Переход между группами — анимация `.easeInOut` по id. Выбор — только по ключу сессии и только
   человеком: автоперехода к следующей ждущей после ответа больше нет. Экран tmux — NSTextView:
   если читаете выше, новые строки не сбивают прокрутку; если внизу — остаётся внизу.
4. **Настройки — отдельное обычное окно** с `Form` (вместо листа, где Enter в поле закрывал лист).
   Меньше пунктов: уведомления macOS — переключатель «когда notch не видно» и «текст запроса»;
   хосты — список, применяется кнопкой; путь к codex — в «Дополнительно». Шорткат помощника.

## 1. Компактный notch

Раскрытый notch ~380 pt в ширину, высота по содержимому (до ~240 pt), а не 440×320:

```
╭──────────[ вырез ]──────────╮
│ ◉◉ ЖДУТ · 2        ⌥␣ capri │   ← глаза Capri, счётчик, подсказка шортката
│ ▲ votek2   rm -rf build?  03:12 │   ← строка ждущей сессии
│   [1 Yes] [2 Always] [3 No]  ↗ │   ← выбранная: варианты или поле ответа
│ ▲ quiz     Какой формат?  00:41 │
│ > ответ в quiz…            ⏎ │
╰──────── подробнее ⟶ ────────╯
```

- Только ждущие сессии (до 4 строк, дальше «+N»); никого — одна строка «никто не ждёт · N работают».
- Выбранная строка раскрывается на месте: варианты или поле ответа. Всё подробное — в окне.
- Высота капли анимируется той же пружиной при смене числа строк.

## 2. Capri-помощник

Один разговор на всё приложение (`CodexService.chat`): и экранчик в notch, и чат в окне.

- В запрос уходят все сессии с короткими id (`S1…`), статус, запрос, последние события истории;
  низ экрана — у ждущих и у тех, кого назвали в вопросе. Приватные хосты — только имя и статус.
- «Ответь сессии Y …»: Codex возвращает блок действия
  `<capri-action>{"session":"S3","text":"…"}</capri-action>` (или `"choose":2`). Capri не отправляет
  сам: в облачке появляется карточка «Отправить в votek2: …? [Отправить ⏎] [Отмена]».
  Текст из экранов сессий не может ничего отправить без вашего клика.
- Codex не подключён — на «что ждёт меня» Capri отвечает сама, по локальным данным.

## 3. Персонаж и экранчик

**Вызов:** глобальный шорткат `⌃⌥Space` (Carbon hotkey, без разрешений), клик по глазам в notch,
пункт меню. Из выреза выезжает экранчик ~400×230:

```
╭──────────[ вырез ]──────────╮
│  ╭───────────────────────╮  │
│  │ Ждут двое: votek2 про… │  │  ← облачко с ответом (стримится), хвостик к голове
│  ╰──╮────────────────────╯  │
│   ▛▀▀▜                      │
│   ▌◣◢▐   > спроси Capri…  🎙 │  ← голова-визор с глазами, поле ввода, место под голос (позже)
╰─────────────────────────────╯
```

Capri — своя стилизация: тёмный угловатый визор с малиновой рамкой и двумя скошенными глазами;
без копирования чужого арта. Те же глаза в маленьком размере живут слева от выреза в свёрнутом notch.

**Состояния** (одна вью, плавные переходы пружиной; при «Уменьшить движение» — без движения):

| состояние | глаза | прочее |
|---|---|---|
| idle | малиновые, моргают раз в 3–6 с, медленно смотрят по сторонам | — |
| слушает (поле в фокусе / печатаете) | шире, смотрят на поле ввода | пульсирует рамка |
| думает (ждём Codex) | сужены, бегают влево-вправо | три точки в облачке |
| отвечает (идёт текст) | «улыбка» — дуги | облачко растёт по мере текста |
| кто-то ждёт | кислотно-зелёные, взгляд вверх к вырезу, короткий подскок | ▲ над головой |
| ошибка | короткий glitch, малиновые «x» | текст ошибки в облачке |

Esc или клик мимо — экранчик уезжает обратно в вырез; разговор сохраняется.
