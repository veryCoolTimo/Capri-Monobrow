# ADR 001: границы первого прототипа

Status: prototype decision, 2026-10-27.

Пользователь попросил сначала каркас и план, затем запускаемый прототип. Первый срез соответствует CAPRI-001; добавлено окно сессий для проверки сценария «кликнул на персонажа → выбрал сессию».

Приложение нативное: SwiftUI/AppKit и bounded WKWebView. Никакого Electron. Переносим только sprite.js, не всю исходную логику Capri Desktop.

Живой spike показал две особенности WKWebView. Локальная file:// текстура вызвала WebGL SecurityError; host теперь передаёт texture через data URI, без ослабления настроек WebKit. Прозрачный WebGL layer также не дал надёжную форму ввода WindowServer. Поэтому используются две маленькие связанные NSPanel: WebKit-панель всегда пропускает ввод, соседняя нативная панель рисует силуэт с alpha 1% и получает события только по этой форме. Прозрачные точки отсекаются WindowServer до доставки события; polling курсора и синтетических кликов нет. Точные формы сильных деформаций остаются отдельной задачей: сейчас hotspot основан на исходном спрайте с небольшим запасом.

Сборка выполняется Swift 6 toolchain в Swift 5 language mode; переход на strict Swift 6 concurrency нужен до подключения настоящего многопоточного Core/IPC.

Данные окна демонстрационные. Адаптеры не имитируют реальное подключение; composer не отправляет команды наружу. Список директории пакетов отражает архитектуру, а не готовность интеграций.

Протокол и reducer TypeScript работают независимо от GUI. Общая IPC-схема и генерация Swift DTO появятся вместе с Core daemon, чтобы сейчас не создавать фиктивный транспорт.

Спрайт используется как локальный fan-art reference. Для публичной сборки потребуется другой пакет с подтверждёнными правами. Attribution и исходная MIT-лицензия сохраняются.
